# Lyoha — портфолио
React + TS + Vite + Tailwind. Деплой: GitHub Pages (Settings → Pages → Source: GitHub Actions).

- Проекты и контакты — `src/data.ts` (пустые контакты скрываются)
- Реальные скриншоты: положи `public/shots/<slug>.jpg` (slug из data.ts, напр. `bupy.jpg`) — заменят рисованное превью

    npm i && npm run dev
